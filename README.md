# SwarmUI-KreaGoneWild

A small SwarmUI extension that applies
[ComfyUI-ConditioningKrea2Rebalance](https://github.com/nova452/ComfyUI-ConditioningKrea2Rebalance)
to both positive and negative Krea 2 conditioning.

## Usage

1. Install the required ComfyUI node using the button in the **Krea Gone Wild** parameter group.
2. Restart the ComfyUI backend when prompted.
3. Select a Krea 2 model and enable **Krea Gone Wild > Enable**.

The extension does nothing unless **Enable** is checked and SwarmUI detects the selected model as Krea 2.
